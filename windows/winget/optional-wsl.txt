# ================================================================================
# Optional group - Linux on Windows (WSL)
# ================================================================================
# Read by install-packages.ps1. The three fields below drive the prompt:
#
# Label:   Windows Subsystem for Linux
# Offer:   pro
# Default:
#
# A real Linux kernel and userland, not a port. This is what Git Bash is not:
# apt works, ELF binaries run, and tools that assume Unix behave as they do on
# macOS or a server.
#
# It is also the only supported way to run Ansible from Windows - the project
# does not support Windows as a control node - and the backend Docker Desktop
# uses. Ansible itself is not a winget package: it is "apt install ansible"
# inside the distro. See MANUAL_INSTALL.md.
#
# Installing this package is NOT enough on its own. Verified on a real machine:
# winget puts the app in place, but wsl.exe then reports
# WSL_E_WSL_OPTIONAL_COMPONENT_REQUIRED, because the Windows optional component
# is a separate thing that winget cannot enable. Three steps, in order:
#
#   1. this package                       (winget, done here)
#   2. wsl.exe --install --no-distribution (enables the component; may reboot)
#   3. wsl --install -d Ubuntu             (the distribution itself)
